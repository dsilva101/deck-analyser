Deck merger

Add multiple files or paste each deck into its own input. The tool totals each card within each deck, including the sideboard, and keeps the highest total across all decks. For example, a deck with 3 main-deck Negates and 1 sideboard Negate needs 4 copies; if another deck needs 2 copies, the merged list keeps 4.

The result is the card pool for building any one of the decks at a time. Output contains just quantities and names. Matching uses the same rules as Inventory check, ignoring printings and foil markers. Copy or download the result, or send it straight to Inventory check to find the cards you still need. This tab works offline and remembers your lists in this browser.

Deck diff

Paste a left and right deck list to see two outputs: cards that appear only in the left list and cards that appear only in the right. Deck Diff only reads numbered card lines, ignoring blank lines, headings, and notes. Copies from the main deck and sideboard are combined in each output. A card that appears in both lists is shared, even when the quantities differ.

Matching uses the same offline rules as Inventory check: names ignore capitalization, extra spaces, editions, collector numbers, foil markers, and curly apostrophes. Double-faced cards match by their front-face name.

Inventory check

Choose or paste a deck and your collection. Text lists and CSVs with card names and quantities are supported, including ManaBox exports. An empty collection means you own no copies. Download or copy the missing list, as card quantities without section headings. Missing copies across both sections are combined.

Copies from all editions, foils, and duplicate collection rows are added together. Names match regardless of capitalization, extra spaces, or curly apostrophes; double-faced cards match by their front-face name. Use the same language and spelling in both lists. There are no online card lookups or spelling corrections in this tab.

Each owned copy is used once, filling the main deck before the sideboard. The comparison only uses the quantities in your collection export; it does not track copies reserved for other decks. Inventory check works completely offline. The last picked files are saved in this browser for your next visit; your collection is never uploaded. Re-select a file to load changes made on disk.

The actual Python checker

This folder has its own deck_rotation.py. Pyodide runs that Python code inside your browser. The page uses a generated copy in python-source.js so it can open from disk without a server. It never reads the original script outside this folder.

Internet, privacy, and caching

Internet access is required to load the Python runtime from jsDelivr and retrieve card data from Scryfall. Your file is read locally. Individual card names and the chosen release cutoff are sent to Scryfall. Successful lookups are cached in this browser for up to 24 hours when browser storage is available. Use “Refresh cached cards” to bypass that cache.

A specific rotation preset

This preserves the January 2027 rules in the supplied script: Standard expansions and core sets released from 2025 onward, plus Foundations. It is not an automatic rotation calendar. The release cutoff excludes later printings; legality and bans come from Scryfall’s current data, so this is not a historical legality checker.

Editing the checker

After editing the local Python file, run python3 build.py in this folder and reload the page. You can also use the checker directly: python3 deck_rotation.py deck.txt.
